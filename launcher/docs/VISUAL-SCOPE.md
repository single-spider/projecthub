# ProjectHub launcher visual scope

Status: exploratory / non-final.

The supplied concept reference is the visual north star rather than a pixel-perfect contract. The present work should establish a convincing physical/mechanical radial object, recursive branch navigation, strong active-path readability, and a compact dormant desktop state. Proportions, materials, ring behavior, animation choreography, and rendering technique remain open to improvement.

Current implementation choices are therefore prototypes, not frozen product decisions.

## Explicitly deferred

- real terminal/editor/Git commands
- project-management and backlog data
- documentation lifecycle features
- AI providers
- plugin APIs
- final menu taxonomy
- migration into the existing ProjectHub application
